# Contributing to the n8n template collection

Thank you for helping improve this community collection of n8n workflow templates.

## Reporting a problem

Open a GitHub issue with the template name and file path, the problem you observed, your n8n version (if relevant), and steps to reproduce it. Do not include API keys, credentials, personal data, or exported workflow secrets.

## Suggesting a documentation correction

Open a pull request with a focused change. Explain what was inaccurate or unclear, link to relevant n8n documentation where possible, and verify that existing template links still work.

## Suggesting a workflow template

Before proposing a new template, check whether a similar workflow already exists. Describe its use case, required integrations, any paid services, and the original creator/source. Only submit workflows you are permitted to share. Remove credentials and sensitive sample data before submitting.

## Review and safety

Templates are provided as examples and may require updates for your n8n version and connected services. Test imported workflows in a safe environment before enabling triggers or actions that send messages, modify records, or incur costs. A pull request is a proposal, not a guarantee of acceptance.
